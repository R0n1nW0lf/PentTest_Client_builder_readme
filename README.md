# Pentest Client Builder

A simple automation script that creates structured folders for penetration testing engagements.  
It prompts for a client or engagement name and sets up organized directories for recon, loots, and reports.

## Features

- Creates a named client folder on your Desktop
- Adds subfolders for:
  - Nmap scans
  - Loots
  - Notes
  - Exploits
  - Web screenshots or downloads

Usage


build_client_folder.sh

Then enter a client name like client2, and it creates:

~/Desktop/client2/
-nmap
-loots
-notes
-exploits
